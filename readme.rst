Shadoof 0.1.0
=====================

A Command line utility for writing to Hilltop

Supports xmls and dsns of xmls (and dsns of dsns...)

Command line utility

> shadoof my_data.xml archive.hts (-r)

-r option (--raw-xml) avoids the xml sanitization that is default - not recommended

Will write the data to archive.hts

Will also record the transaction to archive.accdb
